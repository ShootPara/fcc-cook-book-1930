# First Congregational Church of Kalamazoo Mayflower Guild Cookbook (1930)

This is the static GitHub Pages edition of the corrected 1930 Mayflower Guild cookbook.

`source/` contains the immutable Version 8 editorial source. Run `python tools/build_edition.py` to regenerate `dist/data/recipes.json`, `dist/data/edition.json`, and the canonical-ingredient matching report. The site itself is served directly from `dist/` by GitHub Pages.
